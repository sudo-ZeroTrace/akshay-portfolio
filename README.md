## 🛠️ Technology Stack

- **Framework**: React 19 + Vite
- **3D Graphics Engine**: Three.js (WebGL, custom Torus Knot & Icosahedron geometries, canvas textures, raycaster)
- **Styling**: Tailwind CSS v4, custom CRT scanlines, neon glows, chromatic aberration glitch keyframes
- **Typography**: Google Fonts (`Rajdhani`, `Fira Code`, `Space Grotesk`)
- **Icons**: Lucide React + custom inline brand SVGs
- **Audio Synthesizer**: Web Audio API (procedural cyber clicks, keypresses, and alert sounds)
